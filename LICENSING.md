# Licensing and attribution

TABARC Embroidery Studio's own source and documentation are released under the **MIT licence**. See `LICENSE` for the complete grant and copyright notice.

The standard installation contains no third-party runtime dependencies. Installing the optional `formats` extra adds [pyembroidery](https://github.com/EmbroidePy/pyembroidery), which is also MIT-licensed. Its source isn't bundled here. If future builds redistribute that package, the applicable licence and copyright notices must travel with it.

The [libembroidery](https://github.com/Embroidermodder/libembroidery) C library is zlib-licensed and has not been embedded in this codebase. [Ink/Stitch](https://github.com/inkstitch/inkstitch), [Embroiderly](https://github.com/embroidery-space/embroiderly) and other GPL projects remain external references. [PEmbroider](https://github.com/CreativeInquiry/PEmbroider) has additional licensing conditions. Nothing from those source trees has been copied into this release.

The `.ostch` compatibility reader deals with observed serialised data structures, not proprietary executables. The repository contains only synthetic samples; source artwork, lettering collections and third-party machine exports are not distributed.

Links to other people's work are credited research references, not a claim that their copyright or licence transfers to TABARC.
