# Embroidery software and code references

These are upstream projects, ideas, formats and tools worth checking. **A link does not mean source was copied**, and not everything in this list can be bundled with an MIT project.

| Project | Licence / status to check | Useful for |
| --- | --- | --- |
| [pyembroidery](https://github.com/EmbroidePy/pyembroidery) | MIT; optional runtime dependency | Machine formats, needle events, independent validation |
| [EmbroideryIO](https://github.com/EmbroidePy/EmbroideryIO) | MIT | Java/Android embroidery file I/O |
| [vpype-embroidery](https://github.com/EmbroidePy/vpype-embroidery) | MIT | Vector and plotter-style processing |
| [EmbroidePy](https://github.com/EmbroidePy/EmbroidePy) | MIT | Standalone viewing and editing ideas |
| [EmbroideryMobile](https://github.com/Embroidermodder/EmbroideryMobile) | MIT | Mobile stitch viewing |
| [libembroidery](https://github.com/Embroidermodder/libembroidery) | zlib | C format parsing and `sew` command line |
| [Embroidermodder](https://github.com/Embroidermodder/Embroidermodder) | zlib; experimental | Desktop editing and format conversion |
| [Ink/Stitch](https://github.com/inkstitch/inkstitch) | GPL family | Stitch planning, underlay and lettering workflows |
| [PEmbroider](https://github.com/CreativeInquiry/PEmbroider) | GPL / other additional terms | Procedural pattern fills and creative coding |
| [TurtleStitch](https://github.com/backface/turtlestitch) | Review repository licence | Visual-programming embroidery |
| [TurtleThread](https://github.com/TurtleThread/TurtleThread) | GPLv3 | Python turtle-style stitch drawing |
| [Embroiderly](https://github.com/embroidery-space/embroiderly) | GPL | Counted cross-stitch pattern editor |
| [Embroid-It](https://github.com/kfarr3/embroidit) | BSD 3-Clause | Compact Java editor and PES experiments |
| [Morale](https://github.com/vomitselfie/Morale) | Check repository licence | Standalone digitising and interface ideas |
| [Lilo](https://github.com/Kadwood/lilo) | Check repository licence | Guided desktop digitising workflow |
| [OpenEmbroidery](https://github.com/openembroidery) | Varies by project | DIY machine firmware and G-code control |
| [OpenEmbroidery hardware project](https://github.com/F33RNI/OpenEmbroidery) | Check repository licence | Stepper-controlled embroidery hardware |
| [myembro](https://github.com/linker2k/myembro) | GPLv3 | Android PES viewer |
| [Embroidery Converter](https://github.com/HoangEditor/embroidery-converter) | Check repository licence | Batch machine-file conversion |

The main optional dependency is **pyembroidery**. Everything else is research until deliberately integrated with its licence and actual behaviour checked. Verify current licence files before reuse rather than trusting a repository topic or a search-result badge.
